## 📝 Sobre o Projeto
A **Pesquisa de satisfação** é um script em Python desenvolvido para ajudar a TudoWeb a avaliar o nível de satisfação do atendimento prestados aos seus clientes. O programa utiliza estruturas de repetição (`FOR`) e decisão (`IF/ELIF/ELSE`) para coletar e exibir o retorno da pesquisa.

## 🚀 Objetivo
Proporcionar uma aplicação simples e eficiente para mensurar a satisfação dos clientes da empresa.

> **Nota:** Conforme solicitado para validação, o programa está configurado para **10 entrevistados**. A quantidade total proposta para produção é de 50. Para alterar, edite a variável `TOTAL_ENTREVISTADOS` dentro do bloco `if __name__ == "__main__":` no arquivo `.py`.
